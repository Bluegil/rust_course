# Rust Course Workspace

A six-week Rust learning workspace with one crate per week. It includes a
[GitHub Pages site](https://bluegil.github.io/rust_course/) with demo previews,
a workspace report, and getting-started documentation.

Each week's crate is intentionally a small starting point for course exercises.
Run a demo with `cargo run -p week1` (replace `week1` with any week from
`week1` through `week6`).

Use `make help` to see the workspace's format, lint, test, build, and check
targets. See [Structure.md](Structure.md) for the repository layout.
